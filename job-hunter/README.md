# Job Hunter

MVP separado do Hermes para descobrir, analisar e executar trabalhos de sites, apps, APIs e automações.

## Stack

- Next.js App Router
- Supabase Auth + Postgres + RLS
- GitHub
- Vercel

## Próximos módulos

1. conectores de fontes de jobs
2. scoring com IA
3. geração de proposta
4. aprovação/envio
5. criação de projeto GitHub
6. testes e deploy automático
7. agente de acompanhamento

## Segurança

Nunca coloque chaves secret/service_role no cliente. Use apenas a publishable key no browser e RLS para dados por usuário.
